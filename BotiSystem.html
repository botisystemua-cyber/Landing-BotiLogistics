01 — Можливості

Все необхідне для обліку перевезень.

BotiSystem замінює зошит, Excel, Telegram-чат та три різні застосунки. Один кабінет для диспетчера, прозорий доступ для водія, зручний бот для пасажира.

Все потрібне водієві
в одному застосунку.

Водій бачить лише свій сьогоднішній рейс: пасажирів, оплати, посилки до видачі, наступні зупинки. Жодного зайвого функціоналу.

  • → Список пасажирів з оплатою/готівкою
  • → Чек-лист посилок: видати / прийняти
  • → GPS — автоматично, з телефону
  • → Облік пального і авансів
  • → Зв'язок з диспетчером в один тап

без жодних застосунків.

  • → Оплата карткою або Apple/Google Pay
  • → QR-квиток у чаті
  • → Live-трекінг: де зараз ваш бус

04 — Запуск

Від реєстрації — до першого рейсу
за 1 день.

Не треба IT-команди, не треба переписувати процеси. Імпортуєте маршрути, додаєте водіїв — і працюєте.

КРОК 01

Створіть кабінет

Реєстрація за 2 хвилини. Без картки, без договору — просто email.

КРОК 02

Додайте буси та водіїв

Імпорт із Excel або руками. Водії отримають SMS зі своїм кабінетом.

КРОК 03

Створіть розклад

Маршрути, час відправлення, ціни. Або імпортуйте те, що вже є.

КРОК 04

Запускайте продажі

Лінк на сайт або Telegram-бот — пасажири купують самі.
